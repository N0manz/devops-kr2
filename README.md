# Контрольная работа №2

Богатырев Сергей Александрович, ЭФБО-15-24. Вариант 4.

Счётчик на Flask и Redis, Docker Compose и HTTPS через Nginx.

## Запуск

Скопируйте `.env.example` в `.env`, замените `change_me` на собственный пароль и ограничьте права: `chmod 600 .env`.
Запустите `docker compose up -d --build`.
Приложение доступно на `127.0.0.1:8004`; Redis не публикует порт на хосте.
Конфигурация `nginx/kr2.conf` соответствует учебному варианту 4 и требует сертификат и закрытый ключ на сервере.

Проверки: `docker compose ps`, `docker compose top`, `curl http://127.0.0.1:8004/health`.
Файл `.env` и закрытые ключи не добавляются в Git.
